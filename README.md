# Synora

Synora is a backend engineering laboratory built to acquire and validate real-world backend engineering capabilities through implementation.

## Purpose

The project is intentionally evolved step by step.

Each subsystem exists to develop a specific backend engineering capability rather than to demonstrate a particular technology.

## Current Stack

- Node.js
- Express
- PostgreSQL
- npm
- Git

## Prerequisites

- Node.js
- npm
- PostgreSQL

## Installation

Clone the repository and install dependencies:

```bash
npm install
```
